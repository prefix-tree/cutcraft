Effects that shape an element by its silhouette, for titles, shapes, stickers, Layers and clips: `glow` (with a threshold and a bloom in the element's own colours, and a CSS fallback where the shader cannot run), `outline`, `longShadow` and `bevel`. These names are now built in, so a file that declares its own effect under one of them needs to rename it.
