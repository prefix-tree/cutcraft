Takes the colour out.

## Params

Drawn as a CSS filter; no WebGL needed.

| param | type | default | description |
|---|---|---|---|
| `amount` | number (0..1) | `1` | How much colour to take out: 0 leaves the picture as it was, 1 is fully grey. |
