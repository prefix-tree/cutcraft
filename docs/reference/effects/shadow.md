# `shadow`

Casts a soft drop shadow behind the element's own shape.

## Params

Drawn as a CSS filter; no WebGL needed.

| param | type | default |
|---|---|---|
| `x` | number | `0` |
| `y` | number | `4` |
| `radius` | number (0..200) | `8` |
| `color` | string | `"#000000"` |
| `opacity` | number (0..1) | `0.5` |
